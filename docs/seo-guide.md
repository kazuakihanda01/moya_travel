# MOYA Travel SEO Guide

MOYA Travelで使用するSEO title / descriptionの管理台帳。

このファイルをSEO title / descriptionの正本として管理する。


## 基本ルール

- 各ページごとに固有のtitle / descriptionを設定する
- 地域名、場所、体験内容を自然な文章で表現する
- キーワードを不自然に詰め込まない
- 表示本文とSEO metadataの内容に矛盾を作らない
- title / descriptionを変更する場合は、この台帳と実装を同時に更新する
- canonical / OGP / robots / sitemap / JSON-LD は別工程で管理する
